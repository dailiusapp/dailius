# User Flow

## Purpose

This document defines the main user journeys in Dailius.

The MVP should optimize for the shortest path from signup to experiencing value.

The key moment:

"The AI created a realistic plan that fits my life."

---

# Primary User Journey

## Landing Page

User understands:

- What Dailius does
- Why it is different
- How it helps

Primary action:

Create account

# Authentication

User:

- Creates account

# Onboarding

Goal:

Understand the user's life.

Collect:

- Commitments
- Goals
- Activities
- Availability
- Constraints

---

# Step 1: Fixed Commitments

Examples:

- Work schedule
- Childcare
- Appointments
- Family commitments

Purpose:

Understand immovable time.

---

# Step 2: Goals

Examples:

"I want to run a faster 5K"

"I want to exercise four times per week"

Purpose:

Understand what matters.

---

# Step 3: Activities

Examples:

- Running
- Cycling
- Strength training
- Guitar
- Reading

Collect:

- Frequency
- Duration
- Preferences

---

# Step 4: Constraints

Examples:

- Do not exercise after 8 PM
- Keep Sundays free
- Protect family dinner

---

# Step 5: Generate First Plan

AI creates weekly schedule.

User sees:

- Calendar
- Scheduled activities
- Explanation

---

# Weekly Planner Experience

The user should understand:

- What is planned
- Why it was scheduled
- How it supports goals

---

# AI Interaction

Examples:

## Missed Activity

User:

"I missed my workout."

System:

- Reviews remaining week
- Finds alternatives
- Explains tradeoffs

---

## Priority Change

User:

"Prioritize running for the next 12 weeks."

System:

- Adjusts activity balance
- Maintains constraints
- Generates new plan

---

## New Commitment

User:

"I have to work late Wednesday."

System:

- Recalculates schedule
- Suggests changes

---

# MVP Success Moment

A new user should experience value within:

10 minutes of signup.

They should think:

"This understands my life better than my calendar does."
