# Development Guidelines

## Coding Style

Prefer:

- Simple readable code
- Small components
- Clear naming
- Minimal dependencies

---

## Before adding a feature ask:

Does this help validate the core hypothesis?

Core hypothesis:

"People want AI help deciding when to do the things that matter to them."

---

## Avoid

Do not add:

- Complex abstractions
- Enterprise patterns
- Premature optimization
- Features outside MVP

---

## Every feature should support:

1. User enters life information
2. AI creates plan
3. User interacts with plan
4. AI improves plan
